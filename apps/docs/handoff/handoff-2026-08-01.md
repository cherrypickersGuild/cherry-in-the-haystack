## 7. 알아두면 좋은 것 (gotcha)

- **기사(article) vs 도메인(domain) 구분이 이 시스템의 핵심.** kind가 잘못되면 페이지 형식이 어긋난다. 혼합 분류(domain-applications·product-discovery·discourse의 일부)는 kind로 섹션을 나눈다.
- **원본 디자인 재현 지시**가 자주 있다. 임의로 이모지/리스트로 대체하지 말 것 — 원본 컴포넌트(RankCard 로고 등)를 확인.
- **브라우저 프리뷰가 자주 멈춘다**(read_page 빈 응답/scroll 타임아웃). 검증은 결정적 로직이면 node로 재현(예: Featured 픽 검증)하는 게 확실.
- 로컬 dev 서버는 사용자가 3000에서 이미 실행 중일 때가 많다(에이전트는 3001+ 쓰되, 같은 .next 디렉터리라 두 번째 dev 서버가 안 뜰 수 있음 → 사용자 3000에서 HMR로 확인).
