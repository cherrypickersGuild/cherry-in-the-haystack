> 아래 표에 한 줄씩 남긴다. 목적은 "다시 시도"가 아니라 **"같은 실패가 다시 안 나도록 시스템을 고침"**.
>
> 각 줄: **근인 단계**(어느 게이트가 이걸 잡았어야 했나)와 **추가한 조치**(검수표 새 항목 / 이 지침의 새 규칙 / 자동 테스트·가드)를 반드시 적는다.
>
> ※ 검토 렌즈(§11의 L3 반경·L4 상호작용·L5 주입 등)와 S3 "최소 3회·1회마다 멈춤" 관례는 자매 프로젝트(aiqops)의 실제 실패에서 승격된 것이다. cherry 고유 실패는 아래에 쌓는다.
