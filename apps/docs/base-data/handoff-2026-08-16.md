### 3-1. UI / 네비게이션 (`apps/web/components/cherry/sidebar.tsx`, `app/page.tsx`)
- **사이드바 멀티오픈**: 그룹 헤더 **본문 클릭 = 이동 + 펼치기(절대 안 닫음 → 메뉴 안 튐)**. 오른쪽 **넓은 화살표 존(40×33px)** = 접기/펴기 토글. 여러 그룹 동시 펼침. 펼침 상태 localStorage 저장(`cherry_sidebar_collapsed`). (아코디언/단일오픈은 "메뉴가 튄다"는 이유로 폐기.)
- **기본 접속 페이지 = Overview**: `page.tsx` `useState("nd-overview")`.
- **메뉴 정리**: 사이드바에서 "This Week's Highlights" 항목 삭제. DIGEST 섹션(Patch Notes만)을 **최하단**으로. ⚠️ **highlight 페이지 컴포넌트 자체는 `page.tsx` switch의 `default:` 폴백으로 남아있음**(메뉴로는 도달 불가). 완전 제거 여부는 미결정.

### 3-2. Overview (`apps/web/components/cherry/nd-overview-page.tsx`, `buzz-treemap.tsx`)
- **Buzz Distribution 이관**: Digest highlight → Overview. 위치 = Hero → Worth a Look(spotlight) → Just Added → **Buzz Distribution** → 반복 블록. `CategoryTreemap`에 `showHeader` prop 추가(Overview에선 `SectionHead`로 대체, desc="This week's activity by category"). 데이터는 `fetchLanding()`(없으면 STATIC 폴백). Digest highlight 페이지는 트리맵 빠지고 Trending Momentum 전폭 3열 + Top Picks(단, 이 페이지는 이제 orphaned).
- **히어로 캐러셀 무한 슬라이드**: 양끝에 클론 슬라이드(`[마지막, ...실제, 첫]`)를 두고, 좌우 화살표를 **항상 표시**. 끝을 넘어가면 옆에서 슬라이드로 들어오고, 스크롤 멈춘 뒤(idle 130ms) 동일하게 생긴 실제 슬라이드로 순간 이동해 이음매 제거. 자동재생은 `trackRef`만 참조.

### 3-3. ⭐ kind 전수 재분류 (`public/{cases,research,discourse}/entities.json`)
**판정 기준(방법론 §1.1에 확립):**
- **domain** = 지속되는 실체(제품·모델·툴·프레임워크/표준·조직·뉴스레터·이벤트·데이터셋·마켓맵/랜드스케이프).
- **article** = 특정 발행물 1건(블로그·뉴스·논문·오피니언/분석).
- **`source_type`는 힌트일 뿐, 항목마다 개별 판정.** Research는 **URL 기준 병용**(arxiv/논문 PDF=article, 실제 사이트/HF/github/리더보드=domain).

### 3-4. 렌더링 일원화 — 프론트 정적 도메인 (`nd-landscape.tsx` 외)
- **`StaticDomainLandscape({ base, page })`** 신규(`nd-landscape.tsx`) — 백엔드 없이 `/<base>/entities.json`의 kind=domain을 `domain`별로 그룹핑해 카드로 렌더. 카드/모달 UI는 기존 `LandscapeGrid`(추출) 재사용. **카드 미리보기 최대 5줄 = 4개 + "+N more"**, 카드 클릭 시 **모달에 전체**. 아이콘은 카탈로그와 동일 `makeEmoji`(icons.json `themePools`, 이름 해시로 항목별 다양).
- **혼합 렌더** (도메인 있으면 도메인 섹션 + 기사 있으면 목록):
  - Discourse: `NDDiscourseArticlePage`(nd-research-page.tsx) — 6분류 공용.
  - Research: `NDResearchLandscapePage`(model-updates·benchmarks·papers 공용, `NDPapersPage`가 위임). **model-updates는 HF 인기 순위표(`ModelPopularityRank`)를 맨 위 유지.** 기사 섹션명 "Papers".
  - Cases: `NDCasesBestPage`(domain-applications·product-discovery).
- **⚠️ 백엔드 랜드스케이프는 이제 Engineering(frameworks/prompting) 전용.** ND는 `LandscapeSection`/`RisingStar`/`/api/<page>/landscape`/`generate-{cases,research}-landscape.cjs`를 **안 쓴다**. → **ND는 배포 후 랜드스케이프 재생성 불필요.** (`LANDSCAPE_PAGES` 화이트리스트에 ND 페이지가 남아있으나 미사용 — 나중에 정리 가능.)
- **Featured**: `NDDiscourseArticlePage`·Research 기사 섹션은 `featured` 프롭을 안 넘김 → **Discourse/Research에서 Featured 배너 비활성**(`FEATURED_CFG` 코드는 잔존). 도메인 카드 그룹의 첫 항목 spotlight로 대표 표시.
