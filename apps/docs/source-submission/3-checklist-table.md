## 성과 목표 (완료 기준)

**1~3 — 올리고 본다**

- 유저가 PDF·MD·링크를 올리면 **재배포해도 파일이 남는다**
- 유저는 **자기 투고만** 본다. 같은 자료를 또 올리면 막힌다
- 관리자가 파일·링크를 갈라 보고, 원문은 **눌렀을 때만** 받는다
- 관리자가 아닌 계정은 관리자 경로를 하나도 못 부른다

**4~6 — 분석하고 판단한다**

- [분석하기] 를 눌러야 LLM 이 돈다. 안 누르면 호출 0건
- 서버가 죽어도 **"진행 중" 이 영원히 남지 않는다**
- 승인 전에 **어느 칼럼에 무엇이 들어가는지** 눈으로 볼 수 있다
- 승인해도 **어느 표에도 행이 생기지 않는다.** 잘못 눌렀으면 되돌린다

**안 만든 것** — 기획 §12 에 이유까지 적혀 있다.
